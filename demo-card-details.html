✨ Features implemented:

  • Conditional display: Card details form only shows when "Card" is selected
  • Auto-formatting: Card number formats as you type (1234 5678 9012 3456)
  • Expiry formatting: Automatically formats to MM/YY
  • CVV validation: Only accepts 3 numeric digits
  • Form validation: Order can only be placed when all card details are filled
  • Security note: "Your payment information is secure" message displayed
  • Styled container: Card details form has a subtle sage background to distinguish it
